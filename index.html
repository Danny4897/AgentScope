// Features

Observability built
for C# engineers.

Not a Python tool ported to .NET. Built from the ground up for the way .NET developers actually write AI pipelines.

01

Result.Failure Tracking

In Railway-Oriented Programming, errors don't throw. They flow as Result.Failure values. Sentry, Datadog, Bugsnag — none of them see this. AgentScope does. Every failed Result is captured with full context: domain error code, token cost, span ancestry.

"AgentScope caught 847 silent failures last month that would have gone completely undetected."

02

Pipeline Waterfall

Interactive span hierarchy viewer. See exactly which agent step, LLM call, or tool invocation is costing you time and tokens. Drill down to the millisecond.

03

Real-time Metrics

Latency, throughput, failure rate, and token usage per pipeline. Aggregated at 1-min, 5-min, and 1-hour windows. Live, no refresh required.

04

CircuitBreaker Monitor

Live state transitions: Closed → Open → HalfOpen. Know before your external services fail. Protect your LLM budget from retry storms.

05

Audit Trail

Full chronological log of agent decisions via MonadicSharp.Security. GDPR-ready event sourcing for every AI interaction.

06

2-Line SDK

dotnet add package AgentScope.Sdk. Auto-discovers all ActivitySource traces. Compatible with any OTLP-compatible .NET app. No lock-in, no proprietary agent code.

// Integration

Instrument in
two lines.

That's all it takes. AgentScope auto-discovers your traces through OpenTelemetry's ActivitySource protocol.

// without agentscope flying blind
var result = await agent.ProcessAsync(input);

// result.IsFailure?
// You'll never know.
// Sentry sees nothing.
// Datadog sees nothing.
// The tokens burned.
// The error silently propagated.

return result;
// with agentscope full visibility
// Program.cs — one-time setup
builder.Services.AddAgentScope(options =>
{
options.Endpoint = "https://app.agentscope.io";
options.ApiKey = Environment.GetEnvironmentVariable("AS_KEY")!;
options.ServiceName = "my-ai-pipeline";
});

// That's it. Every trace, span, failure,
// token count — automatically captured.
