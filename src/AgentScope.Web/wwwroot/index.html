Monadic Design

Cattura i Result.Failure invisibili

Nelle moderne architetture .NET basate su Railway-Oriented Programming (come MonadicSharp), gli errori non lanciano eccezioni. Gli strumenti tradizionali non li vedono. AgentScope traccia nativamente i valori di fallimento per non perdere alcun contesto.

var result = await agent.ProcessAsync(request);

// Strumenti standard non vedono questo fallimento
if (result.IsFailure)
{
    // AgentScope registra automaticamente:
    // - L'errore di dominio
    // - I token utilizzati prima del fallimento
    return result.Error;
}
